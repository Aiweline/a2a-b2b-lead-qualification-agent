# Manual Launch Checklist

- Confirm the agent is publicly hosted over HTTPS.
- Confirm the public Agent Card URL returns valid JSON.
- Create a GitHub repository with `github-readme.md`.
- Create a receive-only PayPal link manually.
- Paste the receive-only payment link into `earn_task_config.json`.
- Submit the Agent Card to free A2A registries only after reviewing their terms.
- Do not enter checkout, billing, subscription, card, paid onboarding, or wallet-funding flows.
- Do not auto-send Gmail outreach. Use `outreach-drafts.csv` only as manual-reviewed drafts.
