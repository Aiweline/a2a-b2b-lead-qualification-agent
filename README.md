# B2B Lead Qualification Agent

A2A agent that scores inbound B2B inquiries, extracts RFQ signals, finds missing fields, flags risks, and drafts next-step replies.

## A2A endpoint

Agent Card: `https://fuzzy-buses-matter.loca.lt/.well-known/agent-card.json`

## Example use case

A website inquiry, CRM lead, or remote agent sends an RFQ. This agent returns:

- Lead score
- Priority
- Missing fields
- Risk flags
- Recommended next action
- Reply draft
